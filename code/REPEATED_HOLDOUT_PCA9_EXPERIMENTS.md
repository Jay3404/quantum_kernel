# PCA9 전체 재분할 차원 비교

새 실행은 `cmc_pca9_repeated_20261021`이며 `docs/cmc_pca9_repeated_protocol_20261021.json`을 동결한다. 사용자가 승인한 새 PCA7의 보고·감사·로컬 보관·실제 작업/감시기 종료·슬롯 해제를2026-10-21에 모두 확인한 뒤 준비한다. 기존 중단 `cmc_pca9_20261020`은 재개하지 않는다.

German Numeric/South German/HMEQ, 시드10,20,...,100, 저장된 새 PCA7 가변테스트 분할 그대로다. 전처리/PCA9/5OOF 위험교사/내부3fold sigmoid LR를 새로 적합한다. 원특성 행렬과 저장 분할 및 PCA9의 선행7성분을 PCA7과 대조하지만 점수·모델·검색 prefix를 상속하지 않는다. 수학은 기존 동결된 차원 일반 엔진을 명시적으로 재사용하고 모듈 monkeypatch를 하지 않는다.

기본형, XGB Soft Gate/XGB Rank Append/LR Rank Mixture/PLS Metric, RBF/QSVC 및 기존 모든 셔플·상수·분리형/고전 참조를 유지한다. 30쌍/750중첩PCA/870작업이다. 양수lambda20개, 별도0,3C,3기하, 검증5FN+FP가 고정이다. HMEQ는512랜드마크 근사 검색 후 모든4768학습행 단일 정확SVC와 그 모델의 자기 검증 임계값이다. 예측 앙상블이나 임계값 선택 후 재적합은 없다. 전체870모델/임계값을 잠근 뒤 테스트를 공개하고 잠금/공개 후 새 학습을 막는다.

차원 내 고정138대비에 Holm138, 별도 차원 비교90대비에 Holm90을 적용한다. 90개는 자료당 절대비용10개, 기본형 대비 개선량 차이8개, 자기lambda0 대비 개선량 차이8개, 양자-고전 개선량 차이의 변화4개다. 같은 테스트 고객으로 짝 비교하고 근사 corrected resampled t(df9,분산계수.225), 원p/보정p,95%구간, 시드별 방향, 평균/표준편차를 남긴다. 두 가족의 보정 범위를 숨기거나 유리한 결과만 선택하지 않는다.

CPU85%는 새 작업 입장 기준이다. 최대27개 단일스레드 새 단일작업 프로세스, 메모리80% 및8GiB 추가 여유, 실제9차원 HMEQ8개 전체 크기 측정으로 검색/정확 적합 예산과 별도 정확 슬롯을 결정한다. 압력 시 입장만 지연하고 정상 적합을 종료하지 않는다. CPU Aer9/10큐비트 exact double 상태벡터와 장치별 잠금 GPU Gram을 구분하고512/1024진폭을 포함한6개 CPU/GPU 대조를 수행한다.

실데이터 준비/전체 크기 측정/본실험/감사 실패를 보존하고 자동 재시도하지 않는다. 실행 중 동결 소스·프로토콜·감시기를 수정하지 않는다. 중복 실행이나 과거 마감 재적용은 금지한다. 기존에 본 자료·시드·PCA7 최종 결과에 이어진 탐색적 차원 민감도이며 외부 독립 확인이 아니다. German 두 표현, 겹치는 고객/반복 분할을 독립 자료로 세지 않는다.

`code/run_repeated_holdout_pca9.py`와 독립 `code/monitor_repeated_holdout_pca9.py`를 사용한다. 완료 시 결과/체크포인트 비삭제 로컬 동기화 후 고정 서버에서 `code/validate_repeated_holdout_pca9.py --run-id cmc_pca9_repeated_20261021`로 전체 감사를 수행한다. 최종 보고·보관 후 `pca-9` 자동화만 비활성화한다. 정상 진행은 알리지 않고 실제 시작·새 실패·사용자 조치·완료만 알린다.
